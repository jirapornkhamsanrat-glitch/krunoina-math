# KruNoiNa Math

เว็บไซต์แหล่งเรียนรู้คณิตศาสตร์ออนไลน์ ระดับชั้น ม.1–ม.6
โดย **ครูจิราภรณ์ คำแสนราช (ครูน้อยหน่า)** · โรงเรียนบ้านสำโรง (คุรุประชาสามัคคี)

> **เริ่มต้นที่นี่ 👉 [SETUP.md](SETUP.md)** — คู่มือตั้งค่าระบบแอดมิน (ฟรี ไม่ต้องผูกบัตร)

## หน้าเว็บ

| หน้า | เนื้อหา |
|---|---|
| หน้าแรก | ภาพรวมและทางเข้า 4 หมวดหลัก |
| บทเรียน | หัวข้อบทเรียน ม.1–ม.6 · Fun Zone · คณิตศาสตร์รอบตัว |
| แบบทดสอบออนไลน์ | 12 เรื่อง เรื่องละ 10 ข้อ เฉลยพร้อมคำอธิบาย |
| แจกไฟล์ | ไฟล์งานให้ดาวน์โหลด พร้อมรูปตัวอย่าง |
| ประวัติและผลงาน | ประวัติ รางวัล ผลงานนักเรียน การพัฒนาตนเอง |
| ติดต่อครู | ช่องทางติดต่อ |
| ระบบจัดการ | `admin.html` — แก้ไขทุกอย่างได้โดยไม่ต้องแตะโค้ด |
