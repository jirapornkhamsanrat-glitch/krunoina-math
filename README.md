## ความสามารถหลัก

- บทเรียนแต่ละหัวข้อมีวิดีโอ YouTube ใบงาน และแบบทดสอบประกอบ (ครูใส่เองในระบบแอดมิน)
- แบบทดสอบรองรับสูตรคณิตศาสตร์ (KaTeX) และรูปประกอบโจทย์
- นักเรียนส่งคะแนนให้ครูได้ · ครูดูคะแนนรายห้องและดาวน์โหลดเป็น Excel
- แจกไฟล์พร้อมรูปตัวอย่าง 6 รูป · หน้าฝากกดติดตามเพจก่อนดาวน์โหลดทุกครั้ง
- แดชบอร์ดสถิติผู้เข้าชมและยอดดาวน์โหลด
- สำรองข้อมูล / กู้คืนทั้งเว็บเป็นไฟล์เดียว
- ภาพตัวอย่างเวลาแชร์ลิงก์ · เมนู ☰ บนมือถือ · โหมดสว่าง/มืด
